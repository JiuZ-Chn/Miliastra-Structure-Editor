# 数值模型与设计决策

> 这份文档记录数值平衡背后的**推导逻辑和实测依据**，而不只是当前数值。
> 目的是让任何人（或 AI）接手时能理解「为什么是这个数」，而不是只看到「是这个数」。

## 一、实测基准数据

这些是从游戏里量出来的真实数字，是所有推导的锚点。**修改任何数值前先确认这些还成立。**

| 项目 | 数值 | 来源 |
|---|---:|---|
| 打手丘丘人 1级生命 | 219 | 实测 |
| 火箭丘丘人 1级生命 | 175 | 实测 |
| 火斧丘丘暴徒 1级生命 | 439 | 实测 |
| 敌方6级 打地脉的单次伤害 | 150+ | 实测 |
| 召唤基础成本 | 打手10 / 火箭20 / 火斧30 摩拉 | 配置 |
| 召唤成本递增 | `ceilTo5(base × (1 + 0.15(n-1)))`，全局共享计数 | 配置 |

派生结论：

- **召唤性价比**：打手 21.9 HP/摩拉、火箭 8.8、火斧 14.6。火箭最低，但它是远程单位，站桩输出时间利用率高，实际强度需要实测验证，不能只看 HP/摩拉。
- **地脉没有防御力成长**。`等级倍率.csv` 里有防御力倍率列，但地脉不随等级成长，只有生命值天赋。所以地脉承受**全额伤害**，而单位有等级带来的减免。

## 二、核心数值模型

### 2.1 威胁是乘积，不是平均

最容易犯的错误：把「击杀时间」和「生存时间」当成两个独立指标。实际上承伤会复合：

$$\text{承伤} \approx A_e \times \frac{H_e}{\text{我方DPS}} \quad\Longrightarrow\quad \boxed{\text{威胁} \propto H_e \times A_e}$$

受到的总伤害 = 敌方DPS × 战斗时长，而战斗时长正比于敌方血量。所以**衡量关卡难度的正确指标是敌方生命与攻击的乘积**。

$$\Theta(L)=\frac{H_L}{H_8}\cdot\frac{A_L}{A_8}$$

以「我方1级 vs 敌方8级」为归一化基准。

**踩过的坑**：早期关卡曲线 `5,8,11,15,19,24,30,37,44,52,60,68` 的等级差看着平滑（3,3,4,4,5,6,7,7,8,8,8），但换算成威胁后每关增长 **+77%~+125%**，几乎关关翻倍。表现为「上一关打了50秒通关，下一关不到10秒就失败」。

### 2.2 流量威胁

关卡的实际压力还要乘上刷怪速率：

$$\text{流量威胁} = \text{总到达率} \times \Theta(L) \qquad \text{总到达率} = \sum_i \frac{\text{刷怪概率}_i}{\text{刷怪间隔}_i}$$

这是排关卡难度曲线时的主指标。

### 2.3 余裕比

$$\text{余裕比} = \frac{\Pi_{\text{玩家}}}{\text{流量威胁}} \qquad \Pi = \frac{A_f(1+B_A)}{A_1}\cdot\frac{H_f(1+B_H)}{H_1}$$

经验阈值（实测校准）：

| 余裕比 | 体感 |
|---|---|
| < 1.4 | 紧，容易卡关 |
| 1.8 左右 | 舒适（玩家通关关5时的实测值） |
| > 3 | 偏轻松 |

### 2.4 地脉承伤要用「能挨几下」，不是 DPS

地脉的伤害是**离散大额爆发**，不是持续 DPS。敌16 单次打 368，地脉只有几百血——DPS 模型在这里完全失效。

$$\text{能挨几下} = \frac{\text{地脉生命}}{150 \times A_L / A_6}$$

设计目标：**2.3~3.6 下**。低于 2 下意味着 3 只怪一轮齐射必死；高于 4 下则放怪进来没有惩罚。

## 三、关键设计约束

### 3.1 玩家没有先验知识（最重要）

**玩家不知道「攒到 457 能量买等阶就能通关」。** 他手上有 300 能量时，只会买当下买得起的一两个天赋。任何依赖「玩家预知最优解」的数值设计都会失败。

因此数值必须对**贪心花费**（有钱就花）鲁棒，而不只是对**最优攒钱**成立。

模拟对比（改动前）：

| 关卡 | 贪心余裕比 | 攒钱余裕比 |
|---:|---:|---:|
| 5 | 1.11 | 1.84 |
| 6 | 1.06 | 4.06 |
| 7 | **0.68 打不过** | 2.41 |
| 8 | 1.41 | 1.60 |

根因：**等阶成本远超单关收入**。等阶 L4 要 900 能量，而单关能进主力单位的预算只有 165~284，贪心玩家永远攒不到，被锁死在低等阶。

### 3.2 等阶的每能量收益是专精的 3–8 倍

因为等阶同时提升生命和攻击（功率 = 攻击 × 生命，两个乘区一起涨），而专精只提升一个。

| 节点 | 成本 | 功率增益 | 每能量收益 |
|---|---:|---:|---:|
| 等阶L2（4级→9级） | 250 | ×3.16 | 0.0086 |
| 伤害专精L1 | 75 | ×1.20 | 0.0027 |

这个效率差 × 攒钱门槛 = 两种玩法在中段裂开 6 倍。**降低等阶成本是精准解法**；提高关卡奖励是错误解法（会同时喂养两条路线，导致攒钱玩家末关余裕比飙到 8~10）。

### 3.3 广度路线被严厉惩罚

单位专精（生命/伤害）是 per-unit 的，三个兵种各一份，曲线完全相同（`0/20/45/75/120/180/260/380/550/800`），只是成本不同。

- 同样 1600 能量：全投打手 → 功率 ×59.7；三单位均分 → ×21.4（**2.8 倍差距**）
- 三单位全毕业 51,780 能量 vs 单练 15,350（**3.37 倍**）
- 整树里火箭+火斧的专精共 22,730 能量属于**纯稀释**

这与「玩家均匀布兵就能过」的设计定位冲突。**尚未解决**，见第六节。

### 3.4 开局零收益死锁

玩家打不死怪 → 拿不到摩拉 → 召不出兵 → 更打不死怪。

注意：**被动摩拉产出解决不了这个问题**。卡关时一局只持续约 20 秒，保底产出只跑 4 次，杯水车薪。有效解法是：

1. 开局刷怪缓冲（前 8 秒只开一个刷怪点）
2. 精英怪延后到 10 秒以后出现
3. 保证地脉能扛住几下，让玩家有时间反应
还有一个更彻底的方向：**让击杀本身产出地脉能量**，这样即使卡关也能靠清小怪积累长期收益。初版天赋树里已经设计过这个机制，见 6.4。
### 3.5 百分比治疗与生命上限相乘

治疗量写的是「生命上限的百分比」，所以升级地脉生命时，回复量同步上涨：

$$T_{\text{存活}} = \frac{H}{D - \frac{H \cdot p + F}{2}}$$

分子变大的同时分母在变小，存活时间**发散**而非线性增长。理论上存在「无敌阈值」。

**但实测证明这个担忧在当前量级下不成立**——敌方单次伤害 368，治疗每 2 秒回 19 点，治疗根本不构成平衡因素。所以治疗**没有改成固定值**，保持百分比。如果未来地脉生命再大幅上调，需要重新评估。

## 五、本轮改动记录

按时间顺序，每条都附实测依据。

| 改动 | 原值 → 新值 | 理由 |
|---|---|---|
| 关卡曲线重排 | 等级差均匀 → 威胁等比 | 旧曲线威胁每关 +77~125%，实测「50秒通关，下一关10秒暴毙」 |
| 等阶等级平滑 | `1/3/6/10/16/25/40` → `1/4/9/14/20/29/40` | 旧曲线单档功率跳跃 ×2.07~×4.25，造成大小年 |
| 关6-10 重写 | 原为关2/3/4 的逐字复制 | 关7 流量威胁比关6 还低 13%，出现难度倒退 |
| BOSS 修复 | `是否BOSS=False`、权重列表为空 | 关7/8/9 配置错误，大概率刷不出 BOSS |
| 开局缓冲 | 8秒内 4 点全开 → 只开 1 点 | 关4 二十秒涌入 20.9 只，开局即崩 |
| 精英延后 | 最早 0.03 秒 → ≥10 秒 | 开局精英导致零收益死锁 |
| 地脉生命 | `300…3600` → `540…6480`（×1.8） | 实测单次伤害 368 vs 生命 480，只能挨 1.3 下 |
| 地脉治疗 | `6/10/15%` → `10/15/20%` | 配合生命上调，提升续航 |
| 关6 到达率 | `1.407` → `1.259` | 实测卡关，跨度从 +41% 压到 +26% |
| 441 出现频率 | 每关限一个点位，权重普降 | 关6 原有两个点各 50% 权重，中后期一直在出 |
| 等阶降价 | 打手 `150/250/400/900/1500/2500` → `120/220/380/620/1000/1600` | 贪心路线关7 余裕比仅 0.68，单关收入够不到 900 |

效果：贪心路线最低余裕比 `0.68 → 1.20`，两种玩法差距 `6.0倍 → 3.4倍`。

## 六、待解决问题

### 6.1 广度路线仍被惩罚（优先级高）

单位专精三份重复，玩多兵种要重复付费。候选方案：

- **A. 专精改为全体共享**：6 条单位专精合并为 2 条（【友方】生命提升 / 伤害提升），天赋 16 → 12 条。等阶保持 per-unit（它绑定特性解锁，有设计价值）。
- **B. 火箭/火斧专精打折**：保留结构，成本降到打手的 60%。改动小但只是缓解。
- **C. 按广度路线重新标定关卡难度**：最省事，但深度玩家会觉得太简单。

### 6.2 无尽模式尚未落地

结构定义已建（`config/schema/无尽模式配置.json` 和 `无尽布局配置.json`），但**布局池是空的**，且 `structId` 是按 `0x40400000 + n` 规律推测的（9 和 A），需要用编辑器实际创建后核对。

设计结论：

- 天赋树满配单位功率 `×11,626`（攻击端 ×144.8 × 生命端 ×80.3）
- **敌方106级是算术天花板**——击杀时间与生存时间在此相交（同为 1.67），再往上必输
- 实用上界取**敌方100级**，此时恰好要求单分支 100% 毕业
- 建议：无尽从敌72 起、每层 +2 级，到第 15 层（敌100）为止
- **等级轴到此终结**。之后要继续做无尽，必须换非等级轴（同屏数量、附加词条、精英比例、波次间隔），这些不受等级倍率表约束

### 6.3 需要实测验证的假设

- **火箭的实际强度**。HP/摩拉 只有打手的 40%，但远程单位不用赶路、可以站桩持续输出，时间利用率高。当前分析低估了它。
- **关6/关7 BOSS 重复**（都是 443）。可选 BOSS 只有 `442/444/449/450`，或试试没做过 BOSS 的精英 `455/456/457/459`（不确定是否有 BOSS 血条和 AI）。
- **关2 并发上限 13** 偏高（`#827` 单点 5），高于后续关卡。不影响数值平衡，只影响怪在单一方向的聚集形态。

### 6.4 已废弃机制池（可回收）

`config/archive/天赋树-初版-30条设计.json` 是最早的天赋树（30 条 / 106,150 能量），后来精简到现行 16 条。被砍掉的机制里有几个在当前设计难题下重新有了价值：

| 废弃天赋 | 原数值档 | 为什么值得重新考虑 |
|---|---|---|
| 地脉能量·击杀加成 | 0→5→…→50% | **直接解决 3.4 的零收益死锁**，卡关时清小怪仍有长期产出 |
| 摩拉·击杀加成 | 0→10→…→100% | 局内正反馈，奖励主动清怪而非缩守 |
| 地脉能量·离线收益 | 0→10→…→30% | 长线养成，降低卡关挫败感 |
| 地脉镇石·脉冲攻击 | 开关型 | 范围伤害，对付集群小怪 |
| 地脉镇石·护盾 | 开关型 | 地脉只能扁 2.3–3.6 下，护盾是除生命上限外的第二个调节旋钮 |
| 地脉镇石·无视防御 | 未填 | 地脉不成长防御，此项对它意义不大 |
| 打手·技能强化 / 召唤强化 | 未填 | 当时只做了打手一个单位，属于深度轴 |

注意初版文件是**旧导出格式**：顶层字段为 `type/struct_ype/name/value`（`struct_ype` 是原文的拼写错误），且比现行格式多一层 `.value` 嵌套。解析路径是 `d.value[0].value.value.value`，而现行是 `d.value[0].value.value`。`tools/lib.mjs` 的 `readTalents()` 只支持现行格式。

## 七、给 AI 接手的提示

如果你是被调用来继续这个工作的 AI，请注意：

1. **先读第一节的实测基准**，所有推导都锚定在那几个数字上。不要凭空假设单位或敌人的绝对数值。
2. **威胁用乘积算**（`HP × ATK`），不要用几何平均，也不要把击杀/生存时间当独立指标。
3. **地脉用「能挨几下」评估**，不要用 DPS 模型——它的伤害是离散大额爆发。
4. **任何数值方案都要用贪心策略验证**，不能只验证最优攒钱路线。玩家没有先验知识。
5. **配置里的 `Int32List` 有时只存档位索引**（如地脉治疗），实际数值在游戏逻辑里硬编码。改 JSON 前先确认这一条。
6. `tools/` 下有现成的分析脚本，不要重复造轮子。
