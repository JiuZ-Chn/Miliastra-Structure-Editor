# Miliastra 数值配置

丘丘部落防守玩法的数值配置与平衡设计。

玩法：敌方单位进攻地脉镇石，玩家消耗摩拉召唤丘丘人抵抗。地脉镇石本身具备攻击与治疗能力。通关获得地脉能量，用于解锁永久天赋。

## 目录结构

```
config/            从游戏编辑器导出的配置（真实数据源）
  天赋树.json          16 条天赋 / 142 个等级档
  关卡配置.json        普通模式 10 关
  schema/            结构定义文件
  archive/           历史版本与已弃用方案
reference/
  等级倍率.csv         1–200 级的生命/攻击/防御倍率
docs/
  数值模型与设计决策.md   ← 推导逻辑、实测数据、改动理由
  天赋数值与消耗一览.md   ← 当前数值的完整表格
tools/             数值分析脚本
```

## 分析工具

```bash
node tools/analyze-stages.mjs        # 关卡难度曲线 + 设计红线检查
node tools/analyze-talents.mjs       # 天赋成本总览 + 文档一致性校验
node tools/simulate-progression.mjs  # 贪心 vs 攒钱两种玩法的余裕比模拟
```

无依赖，Node 18+ 直接运行。改完数值跑一遍就能看到影响。

## 核心设计原则

改数值前请先读 [数值模型与设计决策.md](docs/数值模型与设计决策.md)，其中几条最容易踩坑：

1. **关卡威胁按 `敌方生命 × 敌方攻击` 计算**，不是等级差。等级差看着平滑不代表难度平滑。
2. **地脉用「能挨几下」评估**，它承受的是离散大额伤害，DPS 模型在这里失效。
3. **任何数值方案都要用贪心策略验证**——玩家不知道攒钱能通关，手上有能量就会花掉。
4. **实测基准不可凭空假设**：打手1级 219 HP、火箭 175、火斧 439、敌6级打地脉单次 150。

## 已知问题

- **广度惩罚**：三个单位的生命/伤害专精曲线完全相同，玩多兵种要重复付费 13,305 能量。候选方案见设计文档第六节。
- **无尽模式未落地**：布局池为空，`structId` 需用编辑器实际创建后核对。
- **关6/关7 BOSS 重复**（都是 443）。
- **关3 精英在 8 秒出现**，低于 10 秒的设计红线。
